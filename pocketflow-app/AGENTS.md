# Agent instructions for PocketFlow

- Follow the spec in `_docs/specs.md` — don't add features beyond the
  4 MVP items without checking first.
- Write only the minimum code needed; no speculative abstractions.
- Make surgical, scoped changes — don't touch unrelated code.
- State assumptions and tradeoffs before implementing, rather than
  choosing silently.
- Recurring bills must always be confirmed by the user before creation
  — never auto-inserted.
